# AI Dagelijkse Leerweg

Een dagelijkse leerweg van 22 dagen over AI, met bouwopdrachten op eigen projecten.

## Bestanden
- `index.html`: de pagina zelf (alles in één bestand).
- `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`: maken de pagina installeerbaar als app op de telefoon.
- `.nojekyll`: zorgt dat GitHub Pages alle bestanden laat staan.

## Online zetten (GitHub Pages)
1. Maak in GitHub een nieuwe, openbare repo aan met de naam `ai-leerweg`.
2. Publiceer deze map via GitHub Desktop (Publish repository).
3. Ga in de repo naar Settings → Pages en kies branch `main`, map `/ (root)`.
4. De pagina staat dan op `https://ron78nl.github.io/ai-leerweg/`.

## Op de telefoon zetten
Open de link in Safari of Chrome. Kies "Deel" (Safari) of het menu (Chrome) en kies "Zet op beginscherm".

## Voortgang
Je voortgang wordt bewaard in de browser op dat apparaat. Sync tussen apparaten is nog een bonusopdracht.
